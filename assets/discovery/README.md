# Discovery tile artwork

Created with the built-in image_gen tool for Home, Your Spaces and Continue. The coordinated palette matches the viewer's dark navy surfaces with teal and warm gold light. The images contain no text; the card title remains separate and accessible.

Each JPEG is 960 × 480 and under 100 KB. Generated originals were preserved; ImageMagick supplied only delivery resizing, JPEG encoding and metadata removal. No content compositing or third-party stock images.

The exact [generation prompts](prompts.json) record the built-in tool and visual brief for each asset. Existing explicit artwork takes precedence. Defaults come from the shared discovery card service, so web and iPhone build 41 use the same images without a new app install. No space listing, culture, membership or Follow state changes are needed.
